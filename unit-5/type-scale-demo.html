Type Scale & Fluid Type

Three ideas, made visible: a modular scale that derives every size from one base and one ratio, a semantic role layer that names sizes by purpose, and fluid sizing with clamp() shown with a draggable viewport simulator.

1. A modular scale, not arbitrary sizes

Eight named steps. The lower range steps up by roughly a minor third (about 1.2×) per step, so every size relates to the next instead of being a one-off number. Change the base and the whole scale shifts while the proportions hold.

2. Roles give the sizes meaning

A numeric step tells you where a size sits; a role token tells you what it is for. Components consume the role layer, never the steps directly — so re-pointing a role moves every element that uses it, in one edit.

/* Layer 2: roles point at scale steps */ --font-size-display: var(--font-size-4xl); --font-size-heading-lg: var(--font-size-3xl); --font-size-heading-md: var(--font-size-2xl); --font-size-heading-sm: var(--font-size-xl); --font-size-body: var(--font-size-md); --font-size-body-sm: var(--font-size-sm); --font-size-caption: var(--font-size-xs);

3. Fixed vs fluid with clamp()

4. Calculating the preferred value

The preferred (middle) argument is a line through two points: (min-viewport, min-size) and (max-viewport, max-size). Work in px, convert at the end. This is the heading used above — 24px at a 320px viewport, 36px at 1200px:

/* slope = (36 − 24) / (1200 − 320) = 12 / 880 ≈ 0.01364 */ /* = 0.01364 × 100 ≈ 1.364 per 1% of width */ /* intercept = 24 − (0.01364 × 320) ≈ 19.64px */ font-size: clamp(24px, 1.364cqi + 19.64px, 36px); /* verify @ 320px: 1.364 × 3.20 + 19.64 = 24.0px (floor) */ /* verify @ 1200px: 1.364 × 12.0 + 19.64 = 36.0px (ceiling) */

The reading writes this with vw (1% of the real window). This simulator swaps in cqi (1% of the dashed container's width) so the type tracks the slider instead of the browser window — same equation, a container-relative unit. Do the derivation once to understand it, then let a tool like Utopia generate a whole scale of these declarations for you.

The math serves readability — always test type at real widths and nudge the clamp boundaries if an extreme feels off.
